# Zcash Names Blogs

Two Git-backed series live here so contributors can open issues, suggest edits, and publish Markdown directly from the repo.

## Series

### [Users](/blogs/users)

Launches, releases, and early access.

### [Builders](/blogs/builders)

Integrations, tooling, and opportunities.

## How to contribute

All blog pages live under `content/blogs/` in this repository.

- Open an issue for structural changes or missing topics.
- Edit an existing `.mdx` file for copy changes.
- Add a new `.mdx` post file inside one of the series folders for a new post.
